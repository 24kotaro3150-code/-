# lixil-reform.net 加盟店情報スクレイパー

https://www.lixil-reform.net/ に掲載されている加盟店(リフォーム会社)の
「会社名・住所・電話番号・FAX番号」を収集するためのスクリプトです。

会社名・住所は一覧ページに静的に表示されているが、電話番号・FAX番号は
各店舗カードの「問い合わせする」ボタンを押した時に開くポップアップに
JavaScriptで描画される(＝静的HTML取得だけでは取れない)ことがユーザー
提供のスクリーンショットから分かっているため、**ブラウザ操作
(`browser_scraper.py`, Playwright使用)を主に使ってください。**

`scraper.py`(requests + BeautifulSoup)は、電話/FAXが静的HTMLに
含まれるページ(詳細ページ等)が別途見つかった場合の補助用として
残しています。

## 重要な前提

このスクリプトは、実行環境(Claude Codeのサンドボックス)から
`lixil-reform.net` への通信が組織ポリシーでブロックされているため、
**実際のサイトのDOM構造を直接確認せずに作成しています。**
ユーザーが送付したスクリーンショットから読み取れる構造(会社名の見出し、
「住所」ラベル、「詳細を見る」「問い合わせする」ボタン、ポップアップ内の
`TEL 0143-43-3345` / `FAX 0143-43-3347` 表示)を手がかりに、クラス名に
依存しにくいテキスト/ロールベースのセレクタで実装しています。

ロジック(カード特定・住所抽出・ボタンクリック→ポップアップ読み取り・
ページ送り)は、同じDOM構造を再現したローカルのモックページで動作確認済み
ですが、**実サイトでの最終確認・微調整は必ず手元の環境で行ってください。**

## セットアップ

```bash
cd tools/lixil_reform_scraper
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium   # ブラウザ本体をダウンロード
```

## 使い方(browser_scraper.py)

### 1. まず1件だけ処理して抽出結果を確認する

都道府県などで絞り込んだ一覧ページのURLを指定します(サイト上で
「北海道」等を選択した後のURLをコピーしてください)。

```bash
python3 browser_scraper.py "https://www.lixil-reform.net/(絞り込み後のURL)" \
  --debug-first-card --headed
```

`--headed` を付けるとブラウザ画面が表示され、実際にボタンがクリック
されてポップアップが開く様子を目視できます(サーバー等で画面がない
場合は `--headed` を外してヘッドレスで実行してください)。

会社名・住所・電話番号・FAX番号が正しく表示されない場合は、対象ページを
ブラウザの「検証(DevTools)」で確認し、`browser_scraper.py` 内の
以下を実際のDOMに合わせて調整してください。

- `find_card()`: 「問い合わせする」ボタンから店舗カード(会社名・住所を
  含む祖先要素)を辿るXPath
- `extract_card_info()`: カード内の見出し(会社名)・「住所」ラベル後の
  テキストの取り方
- `PHONE_RE`: 電話/FAX番号の正規表現(市外局番のパターンが特殊な場合)
- `--contact-button-text` / `--close-selector` / `--next-page-text`:
  ボタンの文言やページ送りリンクの文言が異なる場合はCLI引数で上書き

### 2. 本走行

```bash
python3 browser_scraper.py "https://www.lixil-reform.net/(絞り込み後のURL)" \
  --output lixil_shops_hokkaido.csv
```

1ページに表示される件数分のカードを順にクリックして電話/FAXを取得し、
ページ番号(1, 2, 3…)またはページ送り矢印(›)をクリックして次ページに
進みます。1ページ目の「◯件中 1〜10件を表示」のような表記から総件数を
読み取り、1ページあたりの件数(1ページ目に実際に表示された件数)で割って
総ページ数を自動計算するため、`368件` のように件数が多い場合も
「何ページまで回れば良いか」を自分で数える必要はありません。全ページを
処理し終えると自動的に終了します。

総件数の表記が読み取れなかった場合や、`--max-pages` を指定した場合は、
ページ送りのリンクが見つからなくなった時点、または指定したページ数に
達した時点で終了します。総件数が368件などページ数が多い場合、既定の
待機時間だと時間がかかります。動作確認できたら `--delay-between-cards` /
`--delay-between-pages` を調整してください。

### 3. 都道府県ごとに実行する

「エリアを選択」で都道府県を切り替えるとURLが変わる場合は、47都道府県分の
絞り込み後URLを手元で控えて、シェルスクリプト等で1都道府県ずつ順番に
実行してください(同時並列実行はサーバー負荷の観点から避けてください)。

```bash
for url in "都道府県1のURL" "都道府県2のURL" ...; do
  python3 browser_scraper.py "$url" --output "lixil_shops_$(date +%s).csv"
  sleep 5
done
```

## 出力

`会社名, 住所, 電話番号, FAX番号, 取得元URL` の列を持つCSV
(UTF-8 BOM付き、Excelでそのまま開ける)を出力します。

## scraper.py(補助・requestsベース)について

電話/FAXが記載された静的HTMLページ(例えば詳細ページ側にラベル付きで
記載されている場合など)が見つかった場合は、こちらの方が高速かつ
軽量です。使い方は同ディレクトリのコード内docstringおよび
`--debug-url` オプションを参照してください。

## 注意点(必ず確認してください)

- **サイトの利用規約を確認すること。** スクレイピングや情報の
  二次利用を制限する規約がある場合は、それに従ってください。
- **robots.txt を確認すること。** `scraper.py` は起動時にrobots.txtを
  取得しDisallowされたパスへはアクセスしませんが、`browser_scraper.py`
  はブラウザ操作の性質上robots.txtの自動判定は行っていません。実行前に
  対象URLがrobots.txtで許可されているか手動で確認してください。
- **アクセス頻度を抑えること。** `browser_scraper.py` は既定でカード間
  0.8秒・ページ間1.5秒待機します。368件×47都道府県のような規模で回す
  場合は特に、対象サーバーに負荷をかけない間隔・時間帯で実行してください。
- **取得したデータの利用目的に応じた法令順守。** 収集した電話番号・
  FAX番号を用いて営業連絡(電話勧誘・FAX広告等)を行う場合は、
  特定商取引法など関連法令、および各社が公表している連絡拒否の意思表示等
  を確認してください。
- User-Agent やブラウザの挙動は、対象サイト運営者が問い合わせ可能な形に
  しておくことを推奨します。
