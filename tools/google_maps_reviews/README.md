# Google マップ 新着口コミ店舗抽出ツール

「世田谷区 リフォーム」のようなキーワードでGoogleマップ検索した際に
上位表示される店舗のうち、**直近一定期間(既定12か月)以内に新しい
口コミが付いている店舗だけ**を、会社名・電話番号・住所・口コミ件数・
平均評価つきで抽出するツールです。

## なぜGoogleマップを直接スクレイピングしないか

Googleマップ/検索結果ページを自動操作で取得することは、Googleの
利用規約で禁止されており、CAPTCHAやIPブロックで早期に止められる
可能性が高いです。そのため、Google公式の **Places API (New)** を
使う方式にしています。規約に沿っており、安定して動作します。

一方で制約もあります。

- Places API から取得できる口コミは**最大5件**までです。そのため
  「1年以内に新着口コミがあるか」の判定は、この5件の範囲での判定に
  なります(6件目以降にもっと新しい口コミがあっても、5件の中に
  古いものしかなければ「対象外」と判定されます)。
- 従量課金制のAPIです(無料枠あり。下記「料金について」参照)。

## 事前準備

1. [Google Cloud Console](https://console.cloud.google.com/) で
   プロジェクトを作成(または既存のものを使用)し、課金を有効にする
   (無料枠の範囲内でも、APIを使うにはプロジェクトへの課金設定自体は
   必要です)。
2. 「APIとサービス」→「ライブラリ」から **Places API (New)** を
   有効化する。
3. 「認証情報」からAPIキーを発行する。セキュリティのため、発行した
   キーは **Places API (New) のみ**に使用制限をかけることを強く
   推奨します。
4. 発行したAPIキーを環境変数に設定する。

```bash
export GOOGLE_MAPS_API_KEY="発行したAPIキー"
```

## セットアップ

```bash
cd tools/google_maps_reviews
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## 使い方

```bash
python3 place_reviews.py --query "世田谷区 リフォーム" \
  --max-results 100 \
  --months 12 \
  --output result.csv
```

- `--query` は複数回指定できます(例: エリアや業種違いのキーワードを
  組み合わせて100件近くまで集めたい場合)。

```bash
python3 place_reviews.py \
  --query "世田谷区 リフォーム" \
  --query "世田谷区 外壁塗装" \
  --query "世田谷区 リノベーション" \
  --max-results 100 \
  --output result.csv
```

- `--months` で「何か月以内の口コミがあれば対象とするか」を調整
  できます(既定12か月)。
- `--max-results` は検索段階で候補として拾う件数の上限です。実際に
  出力されるのは、その中で「期間内に口コミがある」と判定された店舗
  だけなので、出力件数はこれより少なくなります。

## 出力

`会社名, 電話番号, 住所, 口コミ件数, 平均評価, 直近1年以内の最新口コミ日,
Google マップURL` の列を持つCSV(UTF-8 BOM付き、Excelでそのまま
開けます)を出力します。

## 料金について

- 電話番号・評価(rating)を含めて取得するため、Text Search・Place
  Details ともに比較的高い課金ティア(Enterprise系)が適用されます。
  2026年時点でのサードパーティ情報を基にした概算では、1店舗あたり
  おおよそ **$0.05〜0.07(数円〜10円程度)** です。
- 多くのSKUには月あたりの無料枠があり(Enterprise系SKUで概ね月1,000件
  程度)、100件程度のテスト利用であれば無料枠内に収まる可能性が
  高いです。
- **正確な金額は必ずGoogle Cloudの課金ダッシュボードや
  [公式料金ページ](https://mapsplatform.google.com/pricing/) で
  確認してください。** 本ツールのコード自体は料金を保証・制御する
  ものではなく、`--max-results` で呼び出し回数の上限を設定できるのみ
  です。
- 想定外の高額請求を避けるため、Google Cloud Console側で
  「予算のアラート」を設定しておくことを推奨します。

## 注意点

- 取得したデータを営業連絡(電話勧誘等)に使う場合は、特定商取引法
  など関連法令を確認してください。
- Places APIの利用規約・Google Maps Platform利用規約の範囲内で
  ご利用ください。
